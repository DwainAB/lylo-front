# Bienvenue sur la documentation Lylo

**Lylo** est une plateforme de recommandation de parfums personnalisée, propulsée par une IA conversationnelle en temps réel. Les utilisateurs interagissent vocalement avec une parfumeuse virtuelle (Rose ou Florian) pour obtenir des formules olfactives sur mesure.

## Vue d'ensemble

```
Utilisateur → Configure ses préférences → Dialogue vocal avec l'IA → Reçoit sa formule
```

L'application est construite avec **Next.js 16** (App Router) et utilise **LiveKit** pour la communication audio temps réel entre l'utilisateur et l'agent IA.

<Callout type="info">
  Cette documentation couvre l'architecture frontend. L'API backend (`NEXT_PUBLIC_API_URL`) est documentée séparément.
</Callout>
